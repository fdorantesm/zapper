Terminal cleanup for development workspaces

Clean generated files from your projects.

Zapper scans your workspace for folders and files like node_modules, .next, dist, caches, and debug logs. Review the list, select what you want to remove, and delete it from the terminal.

Scan, review, delete.

Run zap --dry-run to inspect matches first. Select rows in the TUI, then press d or enter to remove them.

01 / Inspect

Check what will be removed

Start with zap --dry-run. It shows every match, its path, age, and size without deleting anything.

02 / Select

Select the rows

Move with j/k, select with space, or press a to select all matches.

03 / Delete

Delete and see the total

Press d or enter. When it finishes, zap prints how much space was saved.

Quickstart Commands Default targets TUI keys

Quickstart

Run Zapper from source while developing locally.

go run src/main.go --dry-run

Commands

Use zap when installed as a binary.

zap --dry-run
zap --root ~/workspace --dirs node_modules,dist,.next
zap --yes --dirs node_modules,venv

Default targets

These names are scanned by default and can be replaced with --dirs.

node_modules venv .venv __pycache__ dist build coverage .next .nuxt .turbo .cache target .gradle .terraform debug logs

TUI keys

Navigate and clean without leaving the keyboard.

up/down j/k + c change dir space select : regex filter esc hide filter s sort size a select all d delete enter delete q quit
